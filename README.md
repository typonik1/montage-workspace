# Монтаж · переносимая рабочая среда

Этот репозиторий содержит исходники и проекты для продолжения монтажа в новом GitHub Codespace. ZIP содержит те же материалы, включая полные большие файлы. Готовые ролики и промежуточные рендеры исключены по последнему указанию пользователя.

## Как восстановить

1. На Windows распакуй ZIP целиком в короткую папку, например `C:\Montage`. Имена в архиве записаны в UTF‑8. Для работы открывай репозиторий в новом Codespace через **Code → Codespaces → Create codespace**, либо перенеси распакованную папку в Linux-среду. Основные монтажные команды рассчитаны на Bash.
2. Codespace использует `.devcontainer/devcontainer.json` и при создании запускает `bash setup.sh`. Этот же скрипт запускается вручную из корня. Он подтягивает Git LFS, устанавливает FFmpeg, Python-библиотеки и HyperFrames, затем восстанавливает пользовательские скиллы и шрифт. Существующие скиллы в домашней папке не заменяются. При распаковке ZIP Git LFS не требуется.
3. В новой сессии Bash запусти `source portable/env.sh`. Перед первым HTML-рендером запусти `hyperframes browser ensure`. В облаке Chrome используется через HyperFrames. Установленный браузер и его профили из старой среды не переносились.
4. Проверь `bash setup.sh --check`, затем `ffmpeg -version`, `ffprobe -version` и `hyperframes --version`. Для побайтовой проверки переноса выполни `sha256sum -c portable/SHA256SUMS` до правок. Если файл начинается с `version https://git-lfs.github.com/spec/v1`, выполни `git lfs pull`.
5. Дай новой ИИ прочитать корневой `AGENTS.md`. Если она не подхватывает навыки автоматически, передай ей пути в `.agents/skills/` и `portable/skills/`.

## Проекты и состояние

### «25 лет вместе»

Исходники разложены по сценам. Сценарий, время и сопоставление фотографий находятся в `25_лет_вместе_только_исходники/`. Вступление и финальная HTML-композиция доступны как редактируемые источники. Последний известный полный рендер назывался `25_лет_вместе_2026_v3.mp4`. В переносе его нет. Файл v3 добавлял четыре архивных карточки на 98,15, 109,55, 133,55 и 157,55 секунды поверх v2.

Для повторной сборки после `source portable/env.sh`:

```bash
python build25/make_intro.py
python build25/render_cards.py
hyperframes render build25/outro --fps 60 --quality delivery -o "$PWD/build25/outro.mp4"
python build25/make_audio.py
python build25/assemble.py
python build25/work/v3/render.py
```

Эти скрипты используют относительные к проекту пути и создают локальные промежуточные файлы. Запускай их в свежей рабочей копии или с отдельными именами результатов. Стандартный рецепт выше использует `render_cards.py`. Для исторического варианта сцен с картой глубины сначала запускается `python build25/depth_pass.py`, затем `python build25/render_scenes.py`. Какой из вариантов сцен лежал в основе последнего v2, по сохранённым исходникам подтвердить не удалось. Восстановительный рецепт целиком не прогонялся. HyperFrames 0.9.65 отметил две анимации `letterSpacing` и пересечение анимаций прозрачности в унаследованном финале. Композиция сохранена с исходным визуальным замыслом. Готовый экспорт перенеси в `/workspaces/exports/`.

### «Поджоги и реальные сроки»

Готовая нарезка использовала видео 360 и «Медиазоны», длительность **39,445 с**, субтитры вшиты. Она была добавлена к основному ролику на **2:59,08**. Последний полный результат назывался `Государств_Как_обезоп_с_финальной_вставкой.mp4`, длительность **3:38,52**, формат 1080p. Оба результата исключены. Для пересборки запусти `bash news/render.sh`. `news/project.json` и `news/titles.ass` задают финальные фрагменты. В `news/previous/` лежит промежуточная версия с превью YouTube. Текущая версия использует сам видеоряд и звук.

Источники и редакторская сверка находятся в `news/SOURCES.md`.

### Вспомогательные инструменты

`agent-desktop` и `huashu-art-motion` были чистыми Git-чекаутами. Здесь сохранены их исходники и история версий указана коммитами в `portable/repos.json`. Сборку этих инструментов в новом Codespace не проверяли. Для Rust, подписки на платные модели и специализированных приложений используй инструкции соответствующего инструмента.

## Версии и ручное подключение

Обнаружены FFmpeg и ffprobe `6.1.1-3ubuntu5`, Python `3.14.2`, Node.js `24.22.2`, npm `11.19.1`, HyperFrames `0.9.65`, yt-dlp `2026.10.26` и установленный отдельно nightly `2026.11.22.232654`. `portable/requirements.txt` фиксирует основные версии Python-пакетов. Setup устанавливает FFmpeg из репозитория Ubuntu 24.04 и проверяет версию от 6.1 и наличие `libass` через фильтры.

- OpenMotion `0.0.1` из исходников можно установить отдельно командой `bash setup.sh --openmotion`. Она фиксирует исходный коммит и устанавливает Node.js `26.11.1` рядом с ним, изолированно от основного Node.js. Затем запусти из корня:

  ```bash
  root="$PWD"
  export PATH="$root/portable/.runtime/node26/node_modules/.bin:$PATH"
  export MOTION_DATA_DIR="$root/portable/.runtime/openmotion-data"
  cd "$root/portable/.runtime/openmotion"
  npm start
  ```

  Для другой ИИ настрой stdio MCP по `portable/config/openmotion-mcp.example.json` и подставь абсолютные пути. У Studio и MCP должен быть один `MOTION_DATA_DIR`. Cookie, токены, настройки входа и каталоги runtime исключены. В исходном OpenMotion Workspace обнаружены только служебные данные, проекта для переноса там не было.
- Если нужно снова загрузить YouTube, подключай собственную авторизованную сессию в новой среде. Скачанный 100-секундный исходник уже включён, поэтому для этой сборки повторный вход не нужен.
- Модель Whisper `small` загружается при первом использовании. Сохранённый `news/transcribe-local.py` открывает уже загруженную модель, поэтому сначала при необходимости выполни `python -c "from faster_whisper import WhisperModel; WhisperModel('small', device='cpu', compute_type='int8')"`.
- Для генерации новых материалов заново подключи нужного провайдера вручную. Секреты храни в Codespaces Secrets или в настройках выбранного приложения.

## Что учтено при переносе

В `/workspaces` не найдено монтажных исходников. `card` относится к другому проекту, а `upload-env` содержит восстанавливаемый Python-venv. Из `/tmp` сохранены исходник 360 и рабочие сценарии, а обнаруженные дубли фотоархивов совпадают с архивами в `originals/`. Из `Downloads` сохранён логотип. У второго файла PDF связь с монтажом не установлена. Старое дерево `party25/` отсутствует, его используемый `gsap.min.js` уже находится в `build25/outro/lib/`. Кеш истории HyperFrames заменяется свежим, текущий HTML и все используемые ресурсы включены. Установленные системные навыки `.system` поставляются с самой ИИ и в пользовательскую копию не входят.

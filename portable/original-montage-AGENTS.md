# Навыки проекта «Монтаж»

Подбирай навыки по задаче, даже если пользователь не назвал их явно. Если задача включает несколько этапов, применяй каждый навык там, где он подходит.

- `ffmpeg-skill` для работы с существующим видео и аудио: нарезки, склейки, звука, субтитров, перекодирования и проверки экспорта.
- `vizavi-motion` для создания и доработки анимации, моушн-графики и кинетической типографики.
- `hyperframes` и `hyperframes-cli` для создания, предпросмотра и рендера HTML-видеокомпозиций, в том числе с анимированными титрами, переходами и синхронизацией со звуком. Если нужна режиссура и раскадровка, сочетай с `vizavi-motion`.
  В этой среде запускай CLI с `HYPERFRAMES_CACHE_DIR=/home/codespace/.codex/hyperframes-cache`, чтобы HyperFrames мог использовать браузер для рендера.
- `gpt-fck-frctls` для подготовки промптов, генерации, редактирования и проверки изображений, в том числе кадров и графических материалов для ролика. Применяй его вместе с выбранным способом работы с изображениями.

## Материалы для монтажа

В папке `MONTAGE/` хранится локальная библиотека материалов проекта. Когда для монтажа нужны звуки, фоны или шрифты, сначала проверь соответствующую подпапку:

- `MONTAGE/SFX/` — звуковые эффекты.
- `MONTAGE/Фоны для монтажа/` — фоны.
- `MONTAGE/Шрифты/` — шрифты. Для русскоязычных титров и субтитров проверяй поддержку кириллицы.

Перед выбором нового шрифта для титров или субтитров покажи пользователю несколько вариантов одной и той же фразы на кадре из ролика. Подпиши названия шрифтов и дождись выбора перед применением шрифта в видео.
